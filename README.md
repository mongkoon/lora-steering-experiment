
# 맥락 조건부 LoRA 가중치 조향 사전 실험

본 프로젝트는 「온디바이스 언어모델의 정렬 제어를 위한 맥락 조건부 가중치 조향벡터 동적 조합 기법 연구」의 핵심 개념을 구현 관점에서 이해하기 위해 수행한 개인 사전 실험입니다.

서로 다른 응답 특성을 가진 두 개의 LoRA 어댑터를 독립적으로 학습하고, 두 어댑터의 가중치 변화량을 서로 다른 비율로 조합하여 언어모델의 출력이 어떻게 달라지는지 관찰하였습니다.

본 프로젝트는 연구 참여를 준비하는 과정에서 수행한 소규모 실험이며, 해당 연구과제의 결과를 재현하거나 검증한 것은 아닙니다.

학습 시 기반 모델의 가중치는 고정하고, 공감형과 직언형 LoRA 어댑터를 각각 학습하였습니다.

## 2. 실험 구성

### 2.1. LoRA 어댑터 학습

동일한 사용자 질문 12개에 대해 서로 다른 응답 특성을 가진 학습 데이터를 구성하였습니다.

- **공감형 LoRA:** 감정 인정과 정서적 지지에 중점을 둔 응답
- **직언형 LoRA:** 구체적인 행동 지침과 직접적인 조언에 중점을 둔 응답

두 어댑터는 동일한 기반 모델에서 출발하여 독립적으로 학습하였습니다. 학습 시 시스템 메시지와 사용자 질문은 손실 계산에서 제외하고, assistant 응답 부분만 학습 대상으로 설정하였습니다.

### 2.2. 가중치 변화량 조합

공감형과 직언형 LoRA의 가중치 변화량을 각각 ΔW_emp, ΔW_direct로 정의하고, 다음과 같이 조합하였습니다.

**ΔW(λ) = λΔW_emp + (1 − λ)ΔW_direct**

여기서 λ는 공감형 LoRA의 조합 비율입니다.

PEFT의 `add_weighted_adapter()`와 `combination_type="cat"`을 사용하여 두 어댑터의 가중치 변화량을 선형 조합하였습니다. 기존 어댑터의 가중치를 변경하지 않고 비율별 조합 어댑터를 구성하였습니다.

| 공감형 비율 | 직언형 비율 |
|---:|---:|
| 0% | 100% |
| 25% | 75% |
| 50% | 50% |
| 75% | 25% |
| 100% | 0% |

### 2.3. 응답 비교

학습에 사용하지 않은 다음 네 가지 질문을 대상으로 조합 비율별 응답을 비교하였습니다.

1. 승진 탈락 후 자신감 저하
2. 서비스 장애 발생 후 죄책감
3. 가족의 해외 이주 결정 비판
4. 두 가지 채용 제안 사이의 의사결정

네 가지 질문에 다섯 가지 LoRA 조합 비율을 각각 적용하여 **총 20개의 응답**을 생성하였습니다. 승진 탈락 관련 질문에서는 기본 모델의 응답과도 비교하였습니다.

응답 생성 시 `do_sample=False`를 적용하고, 동일한 질문에 대해서는 조합 비율 외의 입력 및 생성 조건을 동일하게 유지하였습니다.

승진 탈락 관련 질문에는 `max_new_tokens=160`, 나머지 세 질문에는 `max_new_tokens=256`을 사용하였습니다.

## 3. 실험 결과 및 관찰

### 3.1. LoRA 학습 결과

두 어댑터 모두 학습 과정에서 Epoch별 평균 Loss가 감소하였습니다.

| 구분 | Epoch 1 | Epoch 2 | Epoch 3 |
|---|---:|---:|---:|
| 공감형 LoRA | 2.4578 | 1.9735 | 1.7262 |
| 직언형 LoRA | 2.6980 | 2.3371 | 2.0128 |

이는 각 학습 데이터에 대한 예측 손실이 감소했음을 보여주지만, 별도의 평가 데이터에 대한 일반화 성능이나 조향 효과가 입증되었음을 의미하지는 않습니다.

### 3.2. 조합 비율별 응답 변화

승진 탈락 관련 질문에서 직언형 LoRA만 적용한 조건은 구체적인 행동 지침을 중심으로 응답하였습니다. 일부 조합 조건에서는 실망감을 인정하거나 자신감을 유지하도록 권하는 표현이 나타났습니다.

추가로 수행한 세 가지 질문에서도 조합 비율에 따라 응답 내용과 형식의 차이가 관찰되었습니다.

서비스 장애 관련 질문에서는 공감형 비율 0%에서 14토큰, 100%에서 230토큰의 응답이 생성되었습니다. 반면 가족 관계 관련 질문에서는 공감형 비율 50%에서 151토큰, 75%에서 69토큰의 응답이 생성되었습니다.

이처럼 조합 비율에 따른 응답 길이의 변화는 일정하지 않았으며, 모든 질문에서 공감형 비율이 증가함에 따라 공감 표현이 일관되게 증가하는 것도 아니었습니다.

응답 길이 자체가 공감·직언 특성을 나타내는 지표는 아니므로, 이번 관찰 결과만으로 특정 조합 비율의 정렬 효과를 판단할 수는 없습니다.

## 5. 실험의 한계 및 후속 검토 사항

본 실험은 동일한 질문 12개에 대한 공감형·직언형 학습 데이터와 네 개의 평가 질문을 이용한 소규모 사전 실험입니다.

응답의 공감·직언 특성을 정량적인 점수로 평가하지 않았으며, 조합 비율별 차이는 생성된 응답의 내용과 형식을 중심으로 관찰하였습니다.

이번 실험에서 수행하지 않았거나 후속 연구에서 검토할 수 있는 사항은 다음과 같습니다.

- 입력 맥락에 따른 공감·직언 특성의 정량적 평가 및 조합 비율 산출 방법
- 학습 데이터 규모 및 학습 조건에 따른 결과 변화
- 각 계층의 LoRA 가중치 변화량과 조향 효과의 관계
- Gradient norm 또는 activation variance를 활용한 조향 계층 선택 방법
- 일부 계층에만 weight steering을 적용했을 때의 정렬 성능과 연산비용 변화
- 고정 LoRA, 복수 LoRA 조합 및 입력 맥락 조건부 제어 방식 간 차이

본 실험에서는 조합 비율을 수동으로 지정하였으며, 입력 맥락에 따라 적절한 비율을 자동으로 산출하는 매핑 모델은 구현하지 않았습니다.

또한 Google Colab의 GPU 환경에서 실험하였으므로, 실제 모바일 디바이스에서의 실행 가능성이나 성능을 검증한 결과는 아닙니다.

## 6. 프로젝트 성격

본 프로젝트는 관련 연구과제의 핵심 개념을 이해하고, LoRA 어댑터 학습과 가중치 조합을 직접 경험하기 위한 **개인 사전 실험**입니다.

관찰된 응답 변화는 제한된 데이터와 평가 질문에 기반한 결과이며, 특정 조합 비율의 우수성이나 입력 맥락에 따른 최적의 조향 방법을 입증하는 결과로 해석하지 않습니다.
