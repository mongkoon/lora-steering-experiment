
# 맥락 조건부 LoRA 가중치 조향 사전 실험

본 프로젝트는 온디바이스 언어모델의 정렬 제어를 위한 맥락 조건부 가중치 조향벡터 동적 조합 연구의 핵심 개념을 구현 관점에서 이해하기 위해 수행한 개인 사전 실험입니다.

서로 다른 응답 특성을 가진 두 개의 LoRA 어댑터를 독립적으로 학습하고, 가중치 변화량의 조합 비율에 따라 언어모델의 출력이 어떻게 달라지는지 확인하는 것을 목적으로 합니다.

본 프로젝트는 관련 연구 참여를 준비하는 과정에서 수행한 소규모 실험이며, 연구과제 자체의 결과를 재현하거나 검증한 것은 아닙니다.

## 2. 실험 구성

### 2.1 LoRA 어댑터 학습

동일한 사용자 질문 12개에 대해 공감형과 직언형 답변을 각각 구성하였습니다.

두 어댑터는 동일한 기반 모델에서 출발하며, 기반 모델의 가중치는 고정한 상태에서 독립적으로 학습하였습니다.

- 공감형 LoRA: 감정 인정과 정서적 지지에 중점을 둔 응답
- 직언형 LoRA: 구체적인 행동 지침과 직접적인 조언에 중점을 둔 응답

학습 시 시스템 메시지와 사용자 질문은 손실 계산에서 제외하고, assistant 응답 부분만 학습 대상으로 설정하였습니다.

### 2.2 가중치 변화량 조합

각 LoRA의 가중치 변화량을 다음과 같이 조합하였습니다.

ΔW(λ) = λ × ΔW_emp + (1 − λ) × ΔW_direct

λ는 공감형 LoRA의 조합 비율입니다.

PEFT의 add_weighted_adapter()와 combination_type="cat"을 사용하여 두 LoRA의 가중치 변화량을 선형 조합하였습니다.

다음 다섯 가지 비율을 비교하였습니다.

| 공감형 비율 | 직언형 비율 |
|---:|---:|
| 0% | 100% |
| 25% | 75% |
| 50% | 50% |
| 75% | 25% |
| 100% | 0% |

기존 LoRA 어댑터의 가중치는 변경하지 않고, 비율별 조합 어댑터를 구성하여 응답을 생성하였습니다.

### 2.3 응답 비교

학습에 사용하지 않은 네 가지 질문을 대상으로 조합 비율별 응답을 비교하였습니다.

평가에 사용한 질문의 주제는 다음과 같습니다.

1. 승진 탈락 후 자신감 저하
2. 서비스 장애 발생 후 죄책감
3. 가족의 해외 이주 결정 비판
4. 두 가지 채용 제안 사이의 의사결정

동일한 질문에 대해 다섯 가지 조합 비율을 적용하였으며, 총 20개의 응답을 생성하였습니다.

응답 생성 시 do_sample=False를 적용하였고, 동일한 질문에 대해서는 조합 비율 외의 입력 조건을 동일하게 유지하였습니다.

## 3. 실험 결과

### 3.1 LoRA 학습

두 어댑터 모두 학습 과정에서 평균 Loss가 감소하였습니다.

| 구분 | Epoch 1 | Epoch 2 | Epoch 3 |
|---|---:|---:|---:|
| 공감형 LoRA | 2.4578 | 1.9735 | 1.7262 |
| 직언형 LoRA | 2.6980 | 2.3371 | 2.0128 |

이는 학습 데이터에 대한 예측 손실의 감소를 보여주는 결과이며, 별도의 평가 데이터에 대한 일반화 성능이나 조향 효과를 입증하는 결과는 아닙니다.

### 3.2 조합 비율별 응답 변화

직언형 LoRA만 적용한 조건에서는 대체로 간결하고 직접적인 행동 지침이 생성되었습니다.

일부 질문에서는 공감형 LoRA의 조합 비율을 높였을 때 감정을 인정하거나 정서적으로 지지하는 표현이 나타났습니다.

그러나 모든 질문에서 공감형 비율이 증가함에 따라 공감 표현이 일정하게 증가한 것은 아닙니다.

또한 입력 맥락과 조합 비율에 따라 응답 길이와 형식에 차이가 나타났습니다.

예를 들어 서비스 장애 관련 질문에서는 공감형 비율 0%에서 14토큰, 100%에서 230토큰의 응답이 생성되었습니다. 반면 가족 관계 관련 질문에서는 50%에서 151토큰, 75%에서 69토큰의 응답이 생성되었습니다.

따라서 조합 비율에 따른 응답 길이의 변화와 실제 공감·직언 특성의 변화를 구분하여 평가할 필요가 있습니다.
